# Apps Script joke Codes (Google-Docs)
This adds a "little" script for apps scrpt google docs to do jokes.
-
Go to google docs, in the doc you share with your friend and in extensions, open Apps script.  
Paste the script  in the main window, press `Ctrl + s`, close and recharge the doc window.  
You will see a new tab called: External Tools. 
In Input code you can put this codes:  
**·** `1234` adds an image  
**·** `aCrectionMIAU` changes every a or A to MIAU  
**·** `uCrectionGUAU` changes every u or U to GUAU  
**·** `url1ns3rt10n` inserts an URL to a misterious video  
Or `showCodes` to show them in a ui alert.
